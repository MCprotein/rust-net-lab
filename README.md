# Rust로 밑바닥부터 만드는 네트워크 시스템

> TCP·UDP 소켓부터 HTTP, 상태 유지 프로토콜, 미니 inetd까지 직접 구현하는 Rust 네트워크 학습 프로젝트

## 목표

프레임워크가 감춰 주는 부분부터 시작하지 않고, Rust 표준 라이브러리를 사용해 네트워크와 운영체제의 기본 동작을 직접 확인한다.

- TCP 연결과 바이트 스트림 이해
- UDP 데이터그램 통신 이해
- TCP 위에서 HTTP/1.1 요청과 응답 직접 처리
- 연결을 유지하는 상태 기반 프로토콜 설계
- 소켓과 외부 프로세스를 연결하는 미니 inetd 구현
- 동기 구현을 완성한 뒤 비동기 런타임과 비교

## 학습 원칙

- 완성 코드를 복사하지 않고 요구사항부터 직접 구현한다.
- 처음에는 가능한 한 Rust 표준 라이브러리만 사용한다.
- 막히면 정답보다 작은 단위의 힌트를 먼저 확인한다.
- 컴파일 오류와 런타임 오류의 원인을 기록한다.
- 한 단계를 완성한 다음 코드를 보지 않고 다시 구현한다.
- 동작 확인 후에만 리팩터링하거나 비동기 구현으로 확장한다.

## 첫 번째 과제

TCP Echo Server를 구현한다.

- `127.0.0.1:7878`에서 연결을 기다린다.
- 우선 한 번에 클라이언트 한 명을 처리한다.
- 받은 데이터를 문자열로 가정하지 않고 바이트 그대로 돌려준다.
- 클라이언트가 연결을 종료할 때까지 읽기와 쓰기를 반복한다.
- 외부 crate는 사용하지 않는다.

## 실행

```bash
cargo run
```

다른 터미널에서 서버에 연결한다.

```bash
nc 127.0.0.1 7878
```
