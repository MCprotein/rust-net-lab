# Rust로 밑바닥부터 만드는 네트워크 시스템

> TCP·UDP 소켓부터 HTTP, 상태 유지 프로토콜, 미니 inetd까지 직접 구현하는 Rust 네트워크 학습 프로젝트

## 이 프로젝트를 시작한 이유

이 저장소의 목적은 네트워크 서버를 가장 빠르게 완성하는 것이 아니다. Rust로 네트워크와 운영체제의 경계를 직접 다뤄 보면서, 데이터가 실제로 어떻게 오가고 프로그램이 연결과 프로세스를 어떻게 관리하는지 이해하는 것이 목적이다.

완성된 코드를 따라 치기보다 요구사항을 읽고 직접 설계한다. 모르는 내용은 문서와 자료를 찾아보고, 시행착오를 거친 뒤에도 풀리지 않을 때만 힌트를 요청한다. 결과만 동작하는 코드보다 왜 그렇게 동작하는지 설명할 수 있는 코드를 목표로 한다.

## 구현 방향

처음부터 모든 네트워크 기능을 직접 만들지는 않는다. 먼저 Rust 표준 라이브러리의 `std::net`을 사용해 TCP, UDP, HTTP와 상태 기반 프로토콜의 올바른 동작을 익힌다.

동작을 확인한 다음 다음 책임을 분리한다.

- **프로토콜:** 입력 바이트를 어떤 규칙으로 해석하고 어떤 출력을 만들지 결정한다.
- **전송 계층:** 바이트 또는 데이터그램을 실제 네트워크로 읽고 쓴다.
- **애플리케이션:** 연결, 동시성, 종료와 오류 처리 흐름을 조정한다.
- **실행 계층:** 사용할 전송 구현과 설정을 선택하고 프로그램을 시작한다.

두 번째 구현이 필요해졌을 때 실제 변경 지점을 기준으로 경계를 추출한다. 처음부터 미래의 모든 변화를 예상한 거대한 추상화를 만들지는 않는다.

최종적으로는 프로토콜 로직을 유지한 채 `std::net` 기반 전송 구현을 OS 소켓 시스템 콜 기반 구현으로 교체한다. 이 교체가 가능하도록 역할과 책임, 의존성 방향, 동작 계약과 테스트를 관리한다.

```text
Echo · HTTP · Chat · inetd 규칙
                 │
          바이트/데이터그램 경계
             ┌───┴──────────┐
             │              │
      std::net 구현    syscall 구현
```

TCP의 스트림과 UDP의 데이터그램은 의미가 다르므로 하나의 인터페이스로 억지로 합치지 않는다.

## 학습 목표

- TCP 연결과 바이트 스트림의 특성을 이해한다.
- UDP 데이터그램과 메시지 경계를 이해한다.
- TCP 위에서 HTTP/1.1 요청과 응답을 직접 처리한다.
- stateless 애플리케이션과 stateful 연결의 차이를 코드로 확인한다.
- 동시 연결, 공유 상태, 종료와 오류 복구를 경험한다.
- 소켓과 외부 프로세스를 연결하는 미니 inetd를 구현한다.
- 표준 라이브러리 구현과 직접 만든 시스템 콜 구현을 같은 동작 계약으로 검증한다.
- 동기 구현을 완성한 뒤 비동기 런타임이 해결하는 문제를 비교한다.

## 학습 규칙

1. 과제의 요구사항과 완료 조건을 먼저 읽는다.
2. 구현 전에 예상 입출력, 상태와 실패 조건을 글이나 그림으로 정리한다.
3. 최소 20분은 직접 시도하고 컴파일러 메시지와 공식 문서를 확인한다.
4. 검색할 때 완성 예제보다 개념과 개별 API 문서를 먼저 찾는다.
5. 막히면 정답 코드 대신 가장 작은 힌트부터 요청한다.
6. 동작 후에는 실패했던 이유와 새로 이해한 내용을 기록한다.
7. 한 단계를 끝낸 뒤 코드를 보지 않고 핵심 부분을 다시 설명하거나 구현한다.
8. 추상화와 의존성은 실제로 두 번째 구현이나 변경이 나타났을 때 추가한다.

## AI에게 질문하는 방법

질문할 때는 과제 번호와 함께 다음 내용을 전달한다.

- 만들려고 한 동작
- 예상한 결과와 실제 결과
- 직접 시도한 방법
- 컴파일 오류 또는 런타임 현상
- 현재 이해하고 있는 원인

힌트는 다음 순서로 요청한다.

1. 생각할 질문만 요청
2. 관련 개념이나 표준 라이브러리 타입만 요청
3. 의사코드나 함수 책임만 요청
4. 작성한 코드에서 문제 위치만 요청
5. 그래도 해결되지 않을 때 최소 수정 방향 요청

전체 정답 코드는 명시적으로 요청하기 전에는 보지 않는다.
